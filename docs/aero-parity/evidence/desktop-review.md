## Limitations and deliberate differences

No exact pixel equivalence claim for taskbar, wallpaper, Start orb or monochrome app paths. The supported web fonts and OS text rasterization differ from Microsoft screenshot. Historic caption visuals are extended for accessibility by the shared window lane. Website body type remains larger than native shell text for research reading. Mobile uses intentional 44px controls and scrollable taskbar pins instead of attempting a compressed native desktop.

No whole-site accessibility certification, field Core Web Vitals or cross-browser verdict from this lane. Root integrates independent review and broader validation. No commits, push, merge or deploy performed.
