## State/coverage discipline

Hover/pressed/disabled visuals depend on CSS and actual browser rendering, not React Testing Library. This inventory maps available automated behavior without declaring those visuals passed. Empty/error/success states apply to search and clipboard; they do not apply to plain app links or a decorative welcome. Modeless reading windows are not dialogs; only native Search is modal. The one-current-page architecture, temporary local filters/drafts, parent-link Back semantics and unchanged factual claims are intentional contracts.
