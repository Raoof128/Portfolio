# Component and state inventory

[Core shell/window inventory](evidence/frontend-window-component-inventory.md) covers21 interaction families: entry, skip, desktop captions, dock, minimise/restore, close/reopen, maximize/reset, pointer and step geometry, navigation/history, clipboard, language, appearance, search/IME/filters/selection/dismissal and artwork lifecycle integration.

[Artwork/UI inventory](evidence/frontend-component-inventory.md) covers Explorer, previews, Atlas, evidence diagrams,13 original artwork implementations, terminal copy, contact validation/email handoff and404 recovery. Decorative nodes have no invented loading/error/disabled interaction. Loading/error/empty states apply where real asynchronous work or filters exist.

The inventories distinguish source review, specific unit tests, actual browser evidence and unrun native/assistive states. A passing isolated unit does not count as every control having been manually operated in every browser. Detailed five-language source completeness is in the machine manifest and content test record.
